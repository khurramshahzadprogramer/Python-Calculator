# 🧮 Streamlit Mobile Calculator

> A sleek, modern, and fully responsive mobile-style calculator web application built with Streamlit and Python, featuring seamless layout alignment, smooth state management, and an intuitive user experience.

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)

[![UI](https://img.shields.io/badge/Layout-Mobile%20Optimized-success.svg)](#-features)

---

## ✨ Features

- **🔢 Core Arithmetic:** Perform precise Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **📱 Mobile-Optimized Layout:** Clean phone-card interface with harmonized grid alignment designed specifically for web and mobile screens.
- **🛡️ Robust Error Handling:** Graceful prevention and handling of edge cases (such as division by zero).
- **🧹 Clear & Backspace:** Quick reset (`C`) and single-digit deletion (`⌫`) capabilities.
- **💡 Expression History:** Live preview of ongoing calculations directly on the display screen.

## 🚀 Getting Started & Deployment

### Prerequisites

- Python 3.x installed on your system.

### Running Locally

1. Clone or download the repository and navigate to the project directory.
2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Run the Streamlit application:

```bash
streamlit run app.py
```
